# Changelog

## 0.1.3 — Research Reliability and Accuracy

Recover limited intermediate output with scoped source excerpts, add optional persistent research checkpoints, and tighten claim-local numeric checks and citation rendering. Package separately from 0.1.2.

## 0.1.2 — Functional Alpha

Added explicit local and cloud onboarding, discovered-model selection, retry and origin guidance. Added a separately staged, checksummed runtime ZIP, installation and upgrade guides, release verification commands and a local Git baseline. Historical evidence is archived. The existing unpacked path remains suitable for same-ID updates.

## v0.2 development milestone (retains Functional alpha 0.1.1)

Added model-specific configuration, capability discovery, adaptive direct and hierarchical planning, unified chat adapters, reasoning separation, and literal evidence checks. Verified simulated 4K, 32K and 128K profiles. See RELEASE_READINESS.md for remaining beta gates.

## 0.1.1 — 2026-11-11

Hardened citation validation and exports, long-job budgets/provenance and reviewed retry, provider profile preservation and active-request cancellation, endpoint classification, diagnostic redaction/empty response handling, history validation and reduced motion. Verified windowed Helium with real local models and isolated browser regressions. Remains Functional alpha due to real long-summary accuracy failures.

## Completion audit — 2026-11-11

Preserved existing provider setup and manifest configuration. Added explicit diagnostic-inference consent, model-switch serialization, source metadata and stale-source checks, bounded opt-in long-document processing, local DOCX import, history validation/quarantine/rename and expanded security/research/browser tests. Published current test evidence and a 34-feature matrix. Release assessment: Functional alpha; real-model quality and Helium acceptance remain limited.

## 0.1.0 — 2026-11-09

Initial implementation of the SAGE extension: local-first providers, webpage extraction, streamed jobs, context inspection, research workspace, passage references, skills, selection actions, visible transcripts, local PDFs and optional history. Added strict TypeScript, linting, unit/integration/browser tests, local icons, release packaging and documentation.

The initial implementation is superseded by the completion audit above. See docs/VERIFICATION.md for evidence and incomplete release gates; version 0.1.0 does not imply store approval or certification.
