# Security policy

## Report a vulnerability

Check the [repository Security tab](https://github.com/PraneshS19/SAGE/security) for a private vulnerability report option. If it is unavailable, open an issue asking for a private reporting channel and omit the technical details. Include the SAGE version, browser version, affected feature and a minimal synthetic reproduction in the private report. Keep real keys, private documents, browser profiles and sensitive logs out of reports.

## Supported release

Please reproduce on the current Functional Alpha (0.1.3) if practical. See the [security model](docs/SECURITY.md), [privacy guide](docs/PRIVACY.md) and [security audit](docs/SECURITY_AUDIT.md) for implemented controls and known limits.
