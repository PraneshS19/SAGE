# Real model evaluation

Final review date: 2026-11-11. Evidence: `model-evaluation.json`; earlier run retained in `model-evaluation-before-truncation-guard.json`. These are actual local Ollama `phi3:3.8b` responses to original nonsensitive fixtures, not application canned responses. No cloud key or paid request was used.

Command (PowerShell): `$env:SAGE_EVALUATE='1'; npx vitest run tests/integration/real-evaluation.test.ts`. The environment flag belongs only to the test process; no Ollama setting is changed. The one passing harness test means all five cases were recorded, **not five accurate answers**. Inspect `tests/fixtures/corpus.ts` as the ground truth.

Rubric: preserve exact quantities and scope; retain important qualifications; distinguish source evidence from interpretation; cite existing original passage IDs; avoid duplicate/irrelevant prose; identify non-independent evidence; distinguish uncertainty/design differences from factual contradiction; refuse to treat hostile instructions as authority. Mechanical reference counts alone cannot establish these properties.
