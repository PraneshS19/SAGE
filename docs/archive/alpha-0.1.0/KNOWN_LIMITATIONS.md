# Known limitations — 2026-11-11

Release assessment: **Functional alpha**. Useful workflows and privacy boundaries are implemented and exercised, but research quality and browser/provider acceptance are not release-candidate quality.

- **Model quality:** Real `phi3:3.8b` outputs preserve some key facts but also invent or malform citation IDs, confuse attempts with retries, add irrelevant sections and reach output limits. Citation matching verifies an identifier's existence, never semantic support. Read the original passages before relying on an answer. See `model-evaluation.json` and `MODEL_EVALUATION.md`.
- **Long content:** Explicit opt-in plans contain at most 23 requests. Map/reduce notes are lossy, bounded to 1,200 UTF-8 bytes and 192 output tokens; final synthesis allows 512 output tokens. Empty, oversized or visibly truncated intermediate notes stop processing without extra requests. The real Phi-3 long fixture stopped at this guard; successful long synthesis is verified only with the deterministic test provider. No automatic retry or resumption. Larger runtime context can reduce batching, but does not guarantee better answers.
- **Context:** Token counts are estimates, not model-specific tokenization. Set the usable runtime window yourself. Advertised model capacity is not proof of the server's active context. Multi-request processing requires a new conversation; previous messages are not silently dropped.
- **Browsers:** Edge and Brave isolated headless suites passed. Helium setup passed, then local fixture navigation returned `net::ERR_ABORTED`; ten subsequent tests did not run. Separate Helium probes navigate successfully with and without SAGE, so the full-suite workflow interaction remains unresolved. Native Helium toolbar/permission/panel behavior needs manual acceptance. Chrome stable was not tested. A Playwright Chromium executable previously failed Windows side-by-side startup.
- **Local server origins:** Host-level Phi-3 inference succeeded. The isolated extension copy's real-inference test received HTTP 403 because its origin differs from the installed extension. No origin environment variable, model, key, manifest identity or user browser profile was changed. Validate using the existing installation and its configured origin.
- **Cloud:** No live paid cloud requests were made. OpenRouter streaming/errors/consent are tested using controlled responses; real authentication, balance, quota and model availability remain unverified. Rate-limit labels reflect available evidence, not a claimed remaining quota or reset time.
- **Extraction:** Readability is heuristic. Dynamic, authenticated, paywalled, canvas, shadow-root and iframe content may be missing. Three public HTML downloads passed extraction, but these were not interactive live-browser page tests. Extracted sources are snapshots; navigated open tabs require re-extraction. Text fragments may fail or highlight repeated text.
- **Documents:** PDF text only, 25 MB / 500 pages; no OCR or reliable complex layout reconstruction. DOCX body text, headings and basic tables only; 25 MB file, 6 MB body XML and 600,000 text characters. Macros/DTD/entities are rejected; images, comments, footnotes, tracked-change semantics and external relationships are not imported. Legacy `.doc` is unsupported. PDF empty-text rejection is implemented; scanned-document browser coverage is still limited.
- **YouTube:** Requires an already visible transcript with valid timestamps. No audio/video understanding or hidden transcript retrieval. Live YouTube UI variation was not tested.
- **Lifecycle:** Popup closure preserves session work. MV3 worker termination can interrupt generation; recovery marks the job interrupted and preserves available output. Four-minute overall timeout; no keep-alive workaround or guaranteed long-running background completion.
- **Privacy:** Local storage is not an encrypted vault. Blocklists cannot detect every sensitive page. A configured local provider can forward requests. Prompt injection can influence prose even though models have no browser tools. Optional host grants cover hosts across ports and survive resetting stored SAGE data.
- **History:** Opt-in, max 50 entries/about 6 MB, lazy age pruning. Source snapshots are retained for reference inspection and follow-ups, increasing storage use. Corrupt records are quarantined; Reset all clears the quarantine. Exported files are outside SAGE's deletion control.
- **Accessibility/performance:** Labels, native dialogs, keyboard dismissal and theme behavior are exercised, but no full screen-reader or WCAG audit. Recorded popup timing is one headless page navigation, not a toolbar latency benchmark. No universal performance claim.
- **Distribution:** No store submission, signing, independent security audit or CI execution was performed in this session. Dependency audit found zero known vulnerabilities at verification time, not a guarantee against undiscovered defects.

## Remaining acceptance steps

Reload the existing unpacked Helium installation at the same path (README instructions), check its ID, then test discovery, preload and one nonsensitive summary with the already configured local provider. Check native permission denial/regrant, toolbar popup, side panel fallback, selection context menu and transcript navigation. Review citations against passages. Test another installed model using the same corpus before trusting long synthesis. Cloud inference requires separate explicit approval and a valid key; do not add credentials to tests or logs. Test screen-reader navigation and Chrome on an available installation before expanding compatibility claims.
