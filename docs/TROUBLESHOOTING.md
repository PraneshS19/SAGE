# Troubleshooting

| What you see                           | What to do                                                                                                                                                                                                           |
| -------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Local server unreachable               | Open Ollama or start `ollama serve`. Check that the configured loopback URL and port match the running server, then retry.                                                                                           |
| No compatible local models             | Run `ollama list`. Choose and install a chat model with `ollama pull <model-tag>`, then retry and select it.                                                                                                         |
| Ollama 403                             | Copy the installation's extension origin in Settings. Add it to the Ollama allowlist, restart the server and retry. See [platform steps](PROVIDERS.md). For a remote proxy, check its access policy as well.         |
| Permission missing or denied           | Retry the connection from Settings and grant the specific origin. Check browser policy if the prompt is unavailable.                                                                                                 |
| Provider 401 or 403                    | Verify the key, endpoint and model access with the provider. Enter the key only in SAGE Settings.                                                                                                                    |
| 402 or 429                             | Check credits, usage limits and any provider retry time. Retry manually when eligible.                                                                                                                               |
| Inference timeout or incomplete answer | Check that the model is loaded and usable. Reduce selected context, review the effective runtime and output limits, or pick another installed model explicitly. Check partial coverage before relying on the answer. |
| Toolbar popup unavailable              | Find SAGE in the Extensions menu. Check whether the extension is enabled and loaded. Open Settings or the workspace from the extension controls.                                                                     |
| Side panel unavailable                 | Use **Open workspace** for the full-tab fallback where the native panel is unavailable.                                                                                                                              |
| New ID or missing settings             | Verify the original browser profile and absolute extension folder. Reload the original entry instead of uninstalling. If the old entry was removed, use available exports and reconnect providers.                   |
| Update fails                           | Restore the previous runtime files in the original directory and reload. Check that `manifest.json` is directly inside that directory.                                                                               |
