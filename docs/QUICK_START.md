# Quick Start

Open SAGE Settings and select **Get Started**.

- **Local AI:** Install and start Ollama, then install a chat model you choose. In SAGE choose **Set up Local AI**, grant endpoint access and test the connection. Choose one of the discovered models, then select **Test model inference** to verify inference and **Finish setup & open workspace**. See [Provider setup](PROVIDERS.md) if Ollama refuses the browser origin.
- **Cloud AI:** Choose **Set up Cloud AI**, enter your own OpenRouter key and grant access to the configured HTTPS endpoint. Choose a discovered model or enter its exact ID. The initial connection check retrieves metadata. **Test model inference** asks for consent before sending a small test prompt that can incur charges. Choose **Finish setup & open workspace** when ready.

Open an ordinary webpage, open SAGE and select **Summarize**. Inspect the prompt, provider and source passages before confirming. Inspect references in the answer. For a follow-up, type your question and review the conversation included in the next request. You can also import a local DOCX or text PDF. Enable history only if you want saved research in this browser profile.

See [installation](INSTALL.md), [troubleshooting](TROUBLESHOOTING.md) and [privacy](PRIVACY.md).
