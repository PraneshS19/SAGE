# SAGE product audit

Scope is Functional Alpha 0.1.3. The audit follows the 34 capabilities in the [feature matrix](FEATURE_MATRIX.md) through the workspace, settings, background worker and provider adapters. Decisions are based on observable workflows and implementation. Browser captures use synthetic sources.

## Visible elements

- **Popup and workspace.** Retain logo, theme, settings, full-workspace entry, selected source, import, answer actions and composer. Remove repeating taglines, decorative empty-state art and duplicate location labels. Skills and History stay in the workspace navigation.
- **Research and sources.** Keep explicit tab listing and origin grants, individual passages, selection and exclusion. Technical processing controls are disclosed as needed. Document context makes switching back to the page explicit.
- **Settings and onboarding.** Keep Local AI and Cloud AI as separate setup choices. AI Providers has a discovered-model picker and manual ID field. Context and inference options sit under Advanced. Status feedback stays visible and diagnostic details can be expanded.
- **Answer, modal and errors.** Keep source warnings, partial progress, cancellation and actions. Model availability and failure messages are text as well as color. Icon actions have accessible names and tooltips. Privacy Inspector uses a native modal and existing consent rules.
- **Cleanup.** Removed the duplicate full model widget, its unused styles, the unused custom modal backdrop and decorative work-area markup. Existing tests, evidence, user settings and provider adapters are required for release and remain in the project.
